# HK Vision

Repositorio de planificacion para el sitio corporativo de **HK Vision**, empresa enfocada en instalacion de camaras de seguridad, CCTV, ciberseguridad y desarrollo de software en Santiago.

## Objetivo del proyecto

Crear una web corporativa multipagina, elegante y tecnologica, orientada a captar clientes para:

- Casas particulares.
- Condominios.
- Empresas.
- Bodegas.
- Clientes que necesiten seguridad fisica, seguridad digital o software a medida.

## Direccion del sitio

- Idioma: espanol.
- Zona SEO principal: Santiago, Chile.
- Estilo visual: corporativo, elegante, confiable y tecnologico.
- Animaciones: 3D sobrias con Three.js, principalmente en el hero.
- Contacto: WhatsApp, telefono, correo y formulario.

## Tipografia recomendada

- Titulares: **Lexend**.
- Texto: **Source Sans 3**.

Esta combinacion se eligio por legibilidad, confianza y presencia corporativa sin caer en una estetica generica o demasiado informal.

## Documentacion principal

El blueprint completo esta en:

- [`outputs/hk-vision-blueprint.md`](outputs/hk-vision-blueprint.md)

Ese archivo contiene la arquitectura propuesta, estructura de paginas, stack tecnico, diseno, SEO, estrategia de contacto, build order y reglas del proyecto.

## Stack recomendado

- Astro 7.
- TypeScript.
- Tailwind CSS v4.
- Three.js para animacion 3D controlada.
- React islands solo para interactividad puntual, como formulario.
- Vercel o Cloudflare Pages para despliegue estatico.

## Estado actual

Este repositorio contiene la fase de arquitectura y planificacion. El siguiente paso es construir el sitio siguiendo el blueprint.
